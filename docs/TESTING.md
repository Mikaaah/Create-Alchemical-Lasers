# Troubleshooting a processing line

Check the emitter height, horizontal shaft, minimum RPM, selected lens or catalyst, and redstone signal first. Look up the exact recipe in JEI or EMI; pack recipes can differ from standalone examples.

If a recipe does not appear, check the common configuration and your datapack or KubeJS definition. A recipe must use the correct input quantity and processing type. See [custom recipes](RECIPES.md) and [KubeJS integration](KUBEJS.md).

For a bug report, include the recipe, a screenshot of the complete line, installed versions, and whether the issue survives a world reload. [Get help](../SUPPORT.md).
