# Getting started

Requires Minecraft 1.21.1, Java 21, NeoForge 21.1.219+ and Create 6.0.10 within the declared 6.0.x range. The pinned tested build is Create 6.0.10-280. Install Create's matching dependencies. JEI, EMI and KubeJS are optional.

1. Place a Laser Emitter above a horizontal belt or Depot, with one air block between them, like a Mechanical Press.
2. Connect rotational power to either end of the emitter's horizontal shaft. A Create wrench changes alignment. The top does not accept kinetic power.
3. Supply at least 16 RPM. Some recipes require more speed; stress and speed limits are configurable.
4. Right-click with a Power Lens and put sand underneath. The bundled recipe converts sand to glass, including a full stack in one cycle.
5. Sneak-right-click with an empty hand to retrieve the installed catalyst.

Keep the gap clear and redstone off. Right-click installs one catalyst and returns the previous stack. A hopper above the emitter feeds stackable catalysts; automation can access the same inventory from any side.

If a pack disables the default recipes, use its custom recipes instead. Hold the Ponder key on the emitter or lenses for the six tutorials. Recipe viewers display catalyst, input, outputs, duration and minimum RPM.
