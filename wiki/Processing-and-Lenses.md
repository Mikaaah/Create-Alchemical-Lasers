# Processing and lenses

Power, Convergence, Splitting, Eclipse and Growth lenses select recipes and beam colors. The emitter handles belts, Depots and dropped stacks. Lens/catalyst automation uses the item capability; top hoppers can feed it. See [recipes](https://github.com/Mikaaah/Alchemical-Laser/blob/main/docs/RECIPES.md) for quantities, timing, minimum RPM and secondary outputs.
