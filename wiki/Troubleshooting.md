# Troubleshooting

Check matching client/server versions, horizontal shaft power, minimum RPM, the air gap, redstone state and a matching recipe. Unpowered/interrupted cycles retain the input. Old red/blue/purple/white lenses were removed in 0.4.0; review the README before upgrading a world.

Report your Minecraft, loader, Create and mod versions with a reproducible example and relevant logs.
